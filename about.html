About these tools

These tools are set up by me, Matt Sanders, to help with my work at the University of Edinburgh. They are shared publicly on GitHub for others to use or adapt for their own needs.

They were mostly coded through Claude by Anthropic (an AI large language model), with me designing the specifications, testing the tools and making minor adjustments to the code. The image tools were adapted from templates created by my previous team, the Usher Digital Education Unit.

While generative AI was used to write the code, no confidential or personal data was shared with it during development. The tools themselves do not connect to, or send data to, any AI service.

Your data

The tools hosted on this site run entirely in your web browser. Any information you enter is stored locally on your own device (for example, in your browser’s local storage) and is not uploaded or sent anywhere by the tools.

If you clear your browser data, or use a different device or browser, this information will not be available. If you are using a shared computer, remember that other users of that browser may be able to see stored data.

The one exception is the Staff Contacts (Power Apps) version, which is linked from this site but not hosted here. It runs within the University’s Microsoft 365 environment, and any staff information it uses is stored and managed within those University systems, subject to the University’s own policies.

Re-use of code

The full source code is available in Matt’s LEARN Tools GitHub repository. You’re welcome to review it, learn from it, or adapt the code for your own needs.

That permission covers the code only. It does not cover:

  • the University of Edinburgh name, logos and crest, which are trademarks of the University
  • icons used in these tools, which are used with permission and require attribution (see the Module Image Builder for details)
  • image templates adapted from work by the Edinburgh Medical School Digital Education Unit

If you adapt these tools, please remove these assets and replace them with your own, or get permission from the rights holder(s). Links to free and Creative Commons icon and image sites are included on the main tools page.

Privacy

As these tools are hosted on GitHub Pages, GitHub may collect data from your visit in line with its privacy statement. See the GitHub General Privacy Statement for more information.

These pages also load fonts from Google Fonts and code libraries from public content delivery networks. These services may receive basic technical information, such as your IP address, when a page loads. Information you enter into the tools is not sent to them.

Contact and feedback

These tools were created for my work at the University of Edinburgh, so any support is informal and on a best-efforts basis.

Anyone outside the University is welcome to report bugs through GitHub Issues. University staff can contact me directly (my contact details are in the Outlook directory).

AI and data guidance for University staff and students

These tools are not intended to be used with personal data (apart from the Staff Contacts tool), but University staff may find it useful to review the University’s data protection guidance.

Guidance on the risks, opportunities and appropriate use of generative AI for staff and students is available at Guidance for students and staff on AI use.
