Course rollover audit

Find what needs updating before a course runs again: dates and times, unfilled template text, links that break when the course is copied, live session links, readings outside the Resource List, videos, external links and file names. Everything happens in your browser, so the course files are never uploaded anywhere.

  1. Choose the export file

    How do I export a course from Learn?

    In your Ultra course, open the More options menu (⋯) at the top of Course Content and choose Export course. Learn prepares the package in the background. When it's ready, download the zip file it creates.

    Use the export exactly as you downloaded it. Don't unzip it first.
